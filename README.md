# Nadia El Ferkane-Blanc — Thérapie familiale

Site vitrine en français pour Nadia El Ferkane-Blanc, thérapeute familiale systémique, formatrice et intervenante en analyse des pratiques professionnelles.

## Développement

```bash
npm install
npm run dev
```

Production :

```bash
npm run lint
npm run build
npm start
```

Les informations publiées sont vérifiées sur le site source [therapie-familiale-systemique.com](https://www.therapie-familiale-systemique.com/). Le portrait de Nadia est conservé dans `public/images/nadia-el-ferkane-blanc.png`.
